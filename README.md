## ⚖️ Core Principles

1. **Probabilistic Estimation:** Authentica AI is an AI-based probabilistic estimation system, **not** a deterministic forensic proof tool.
2. **Zero Infallibility Guarantee:** The system never claims 100% certainty or forensic proof.
3. **Score Nomenclature:** Model outputs are designated as **AI Detection Scores (Uncalibrated Softmax Scores)**.
4. **Mandatory Disclaimer:** Every analysis output displays:
   > *"This result is an AI-based estimate and is not definitive proof of whether the content was generated by AI."*

## 🔍 Multimodal Detection Pipelines

### 1. 🖼️ Image Detection Pipeline
* **Model:** `umm-maybe/AI-image-detector` (Vision Transformer backbone fine-tuned on diffusion outputs).
* **Preprocessing:** Safe PIL decoding, EXIF orientation transposition (`ImageOps.exif_transpose`), multi-mode conversion (RGBA/Grayscale $\to$ 3-channel RGB), Bicubic resizing to $224 \times 224$, and ImageNet normalization.
* **Score Extraction:** Extracts softmax probability with inverted label mapping ($S_{\text{AI}} = 1.0 - P(\text{human})$).

### 2. 📝 Text Detection Pipeline
* **Model:** `Hello-SimpleAI/chatgpt-detector-roberta` (RoBERTa-base fine-tuned on the Human ChatGPT Comparison Corpus HC3).
* **Preprocessing:** NFKC Unicode normalization, whitespace cleaning, minimum length validation ($>50$ characters), and sliding-window chunking (max 512 tokens with 50-token overlap).
* **Score Extraction:** Aggregates chunk-level forward passes via mean and peak scoring.

### 3. 🎵 Audio Detection Pipeline
* **Model Checkpoint:** `garystafford/wav2vec2-deepfake-voice-detector` (`Wav2Vec2ForSequenceClassification` with 24 hidden layers, 1024 hidden dimension, 16 attention heads, ~315M parameters).
* **Preprocessing:** Raw mono 16,000 Hz resampling via `Wav2Vec2FeatureExtractor`, waveform peak normalization, and 4-second chunking.
* **Label Mapping Contract:** Verified at runtime as `Class 0: 'real'`, `Class 1: 'fake'`.
* **Score Nomenclature:** Output is strictly designated as an **Uncalibrated Softmax Score** ($S_{\text{AI}} \in [0.0, 1.0]$).
* **Domain Limitations:** Trained on English speech benchmarks (ASVspoof 2021, Deepfake-in-the-Wild, ElevenLabs, Amazon Polly). Performance on unseen zero-shot generators (e.g. Google Gemini, XTTS) and non-English phonetic structures is subject to domain shift.
* **Provenance:** Provenance verification (e.g., Google SynthID, C2PA) is decoupled from acoustic classification and marked unavailable unless cryptographic verification keys are provided.

### 4. 🎬 Video Detection Pipeline & Late Fusion
* **Visual Stream:** OpenCV uniform temporal keyframe extraction ($N=8$ frames) passed through `ImageDetector` with full spatial resolution preservation.
* **Audio Stream:** Demuxed with RMS energy validation; silent/unvoiced tracks are filtered out to prevent dilution.
* **Weighted Late Fusion:**
  $$S_{\text{video}} = w_{\text{visual}} \cdot S_{\text{visual}} + w_{\text{audio}} \cdot S_{\text{audio}}$$
* **Synthetic Dominance:** High visual AI confidence ($S_{\text{visual}} \ge 0.65$) takes precedence ($85\%-90\%$ weight) over non-synthetic ambient audio.

## 📊 Decision Classification Framework

Predictions are partitioned into three distinct operational intervals:

$$\text{Verdict} = \begin{cases} 
\text{LIKELY AI-GENERATED} & \text{if } S_{\text{AI}} \ge 0.65 \\ 
\text{LIKELY HUMAN-CREATED} & \text{if } S_{\text{AI}} \le 0.35 \\ 
\text{UNCERTAIN (HYBRID MIXTURE)} & \text{if } 0.35 < S_{\text{AI}} < 0.65
\end{cases}$$

## 🧪 Evaluation & Zero-Fabrication Policy

In adherence to strict academic integrity:
* **Zero Fabrication:** No metrics (Accuracy, Precision, Recall, F1, ROC-AUC, Confusion Matrix) are ever hardcoded or simulated.
* **Held-out Evaluation:** Metrics are computed dynamically by executing offline evaluation runners against real, labeled test sets.
* **Artifact Generation:** Evaluation scripts generate JSON metrics (`reports/metrics/`) and publication figures (`reports/figures/`).

---

## 🛡️ File Security & Validation

Every uploaded file is treated as untrusted input and validated via `src/utils/file_validator.py`:
1. **Magic Bytes Inspection:** Verifies binary headers across JPEG, PNG, WebP, WAV, MP3, FLAC, MP4, WebM to prevent file extension spoofing.
2. **File Size Enforcement:** Enforces modality-specific size caps (Image: 15MB, Audio: 25MB, Video: 50MB).
3. **Filename Sanitization:** Strips directory traversals and special characters.

## 💻 Installation & Setup

### Prerequisites
* Python 3.10+
* Git

### 1. Clone the Repository
```bash
git clone https://github.com/Gautamzero30/ARTIFICIAL_INTELLIGENCE_PROJCET.git
cd "ARTIFICIAL_INTELLIGENCE_PROJCET"
```

### 2. Create and Activate Virtual Environment
```bash

source .venv/bin/activate
```

```bash
pip install -r requirements.txt
```

## ⚖️ Ethical Limitations & Disclaimer

1. **Adversarial Resilience:** Light post-processing (e.g. heavy JPEG re-compression, audio resampling, text paraphrasing) can degrade detector accuracy.
2. **Generator Drift:** Detection reliability may decrease when evaluated on unseen generation models not represented in the training distribution.
3. **Responsible Use:** Authentica AI is designed as a research and decision-support tool. It must never be used as sole forensic proof for punitive or disciplinary actions.
